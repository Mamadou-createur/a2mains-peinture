VERSION ADMINISTRABLE

Après avoir remplacé les fichiers du dépôt GitHub :
1. Dans Netlify, activez Identity.
2. Dans Identity, choisissez les inscriptions « Sur invitation uniquement ».
3. Activez Git Gateway.
4. Invitez l'adresse e-mail de l'administrateur.
5. Ouvrez https://votre-site.netlify.app/admin
6. Dans « Galerie photos », ajoutez les photos puis cliquez sur « Publier ».

Chaque publication déclenche automatiquement la mise à jour du site.
